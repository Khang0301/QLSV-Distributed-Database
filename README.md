# QLSV Distributed Database

Distributed Database project for the Distributed Database course.

## Architecture

The system consists of two SQL Server sites:

- Site 1: Machine 1
- Site 2: Machine 2

The project uses:

- SQL Server 2022
- SQL Server Management Studio
- T-SQL
- SQL Server Linked Server
- MSOLEDBSQL
- Node.js
- Express.js
- mssql
- React
- Vite

## Main Concepts

- Simple Predicates
- COM_MIN
- Minterms
- Horizontal Fragmentation
- Fragment Allocation
- Distributed Query
- Reconstruction
- Completeness
- Disjointness
- Failure and Recovery
