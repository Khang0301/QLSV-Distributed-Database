## Connectivity Requirements

The following must be available before Linked Server configuration:

1. SQL Server service running
2. TCP/IP enabled
3. SQL Server remote connections enabled
4. SQL Server TCP port accessible
5. Windows Firewall configured
6. Machine 1 can reach Machine 2
7. Machine 2 can reach Machine 1
